## 1. Nyalakan Docker (dari WSL)
Buka Docker desktop

nyalakan di container 'infra'

## 2. Migrasi database
```powershell

cd C:\Users\HP\Documents\marketplace
$env:DATABASE_URL = "postgres://kantin:kantin@localhost:5432/kantin?sslmode=disable"
migrate -path services/api/migrations -database $env:DATABASE_URL up
migrate -path services/api/migrations -database $env:DATABASE_URL version

# Harus: 9
```

## 3. Seed data demo (sekali)
```powershell

cd C:\Users\HP\Documents\marketplace\services\api
go run ./cmd/seed
cd ../..

```

## 4. Jalankan Backend — Terminal 1 (jangan ditutup)
Buka terminal PowerShell baru:
```powershell

cd C:\Users\HP\Documents\marketplace
Get-Content .env | ForEach-Object {
  if ($_ -match '^\s*([^#=]+)=(.*)$') {
    [Environment]::SetEnvironmentVariable($matches[1].Trim(), $matches[2].Trim(), 'Process')
  }
}
$env:DATABASE_URL = "postgres://kantin:kantin@localhost:5432/kantin?sslmode=disable"
cd services/api
go run ./cmd/api

```
Tunggu log: `memulai API kantin kampus ... addr :8080`.

## 5. Jalankan Frontend — Terminal 2
Buka terminal PowerShell baru:
```powershell

cd C:\Users\HP\Documents\marketplace\apps\web
npm run dev

```
Tunggu `Local: http://localhost:3000` → buka browser.
