## Temuan (angka dilanjutkan)

10. **[HIGH] Riwayat antrian admin belum tersedia di backend yang berjalan** — panel admin tetap kosong/gagal
    sampai Terminal 1 di-restart. Dengan biner lama, rute admin menjawab 404 dan pesan error generik adalah
    satu-satunya petunjuk. *(R-27: UI wajib punya jalur pemulihan nyata; R-38: jangan tampilkan data yang belum ada.)*

11. **[HIGH] Timeline status pesanan menampilkan waktu yang mustahil akurat** — `order-timeline.tsx` mencoba
    `Date.parse` pada `payment.id`/`fulfillment.id` yang merupakan UUID, sehingga setiap tahap yang bukan
    pembuatan selalu tampil "Waktu belum tercatat". Data model memang belum punya kolom waktu transisi.
    *(R-38: informasi harus jujur; C-5: klaim waktu harus terverifikasi atau tidak ditampilkan.)*

12. **[HIGH] Foto utama detail produk memakai lazy loading** — kartu produk di katalog boleh lazy, tetapi gambar
    besar yang langsung terlihat di `/products/[id]` memakai `loading="lazy"` via `ProductPhoto`, sehingga LCP
    tertunda. *(R-40: foto utama tidak boleh lazy, gunakan `fetchpriority="high"` tanpa lazy.)*

13. **[HIGH] Kontrol akun di header landing mengarah ke `/catalog` untuk semua peran** — tautan nama akun di
    `landing-header.tsx` (desktop dan mobile) selalu ke `/catalog`; Seller/Admin yang mengklik dilempar oleh guard
    kembali ke beranda peran mereka. *(R-24: setiap tautan akun harus menuju tujuan yang sesuai peran.)*

14. **[HIGH] Tombol "Buka Keranjang" di bottom bar keranjang tingginya < 44px** — `cart-bar.tsx` memakai
    `py-2.5 text-xs` tanpa tinggi minimum, di bawah standar target sentuh. *(R-03: target minimal 44px.)*

15. **[LOW] Konten Seller dan Admin melebar hampir selebar layar** — halaman stan, produk, detail produk, dan kartu
    admin memakai lebar penuh tanpa `max-w-*` dan tanpa pembagian dua kolom untuk field/kartu berkaitan; banyak
    ruang kosong di sisi kanan pada layar lebar. *(R-05: proporsi dan hierarki komposisi.)*

16. **[LOW] Status pemenuhan tampil dua kali di kartu pesanan Seller** — `order-queue.tsx` menampilkan baris
    "Status pemenuhan: …" dan `FulfillmentControls` menampilkannya lagi sebagai "Status berikutnya: …" atau garis
    status terminal. *(R-05: pengulangan informasi melemahkan hierarki.)*

17. **[LOW] Produk terakhir sendirian di grid 3 kolom saat jumlah produk 4** — showcase menampilkan 4 kartu dalam
    grid `xl:grid-cols-3`; kartu keempat sendirian di baris kedua. *(R-05: komposisi dan keseimbangan layout.)*

18. **[LOW] Blok informasi cakupan pilot terasa berat sebelah** — kolom teks kiri ("Jangan memakai build ini…")
    tidak terhubung secara visual dengan kedua panel daftar di kolom kanan; bobot visual antara keduanya tidak
    seimbang. *(R-05: hubungan konten seharusnya diwujudkan juga dalam komposisi.)*

19. **[LOW] Catatan akun Admin pada halaman Peran menempel pada bagian Buyer** — paragraf "Akun admin tidak dibuka"
    berada di kolom kiri pada baris Buyer, bukan di dekat artikel Admin atau sebagai catatan tersendiri.
    *(R-05: pengelompokan konten sesuai hierarki semantik.)*

## Yang sudah diperiksa dan TIDAK menjadi temuan

- Tidak ada em dash (`—`) di seluruh teks yang dipindai.
- Klaim/angka palsu: tidak ditemukan; angka hanya dari API/PRD (DESIGN.md).
- Kontras: DESIGN.md mencatat pengukuran AA seluruh pasangan warna (termasuk muted 5.41:1); spot-check
  konsisten dengan berkas itu.
- State empty/loading/error: katalog, produk, keranjang, sesi, stan, produk seller, admin orders semuanya punya
  skeleton, error + retry, dan empty state.
- Keyboard: tab Pengaturan dan tab admin memakai role=tablist/tab/tabpanel dengan Arrow/Home/End; dialog terjebak
  fokus dan tertutup Escape; skip link ada di setiap halaman; focus ring terlihat.
- `Button` default `md`/`lg` = 44px minimum; `sm` = 40px (dua kepadatan).
- Verifikasi: `tsc --noEmit` LULUS (exit 0), `vitest run` 14/14 LULUS. `go build ./...` LULUS; `go vet` bersih.

## Yang TIDAK bisa diverifikasi dari sesi ini

- Viewport mobile (browser hanya 1000px): tidak ada pengukuran breakpoint fisik; klaim mobile tidak diukur.
- Alur klik penuh Admin dan Seller: sesi browser keluar (anonim) selama audit; halaman tersebut diverifikasi
  lewat kode dan hasil kompilasi, bukan klik nyata.
- Restart backend Terminal 1: di luar jangkauan audit ini; verifikasi nyata #10 menunggu itu.
